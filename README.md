# sphuta-ui

A Vite + React + Tailwind CSS scaffold for the Sphuta UI (converted from an existing UI). This project includes a responsive layout (Header, Hero, Projects, Contact, Footer) and React Router for navigation.

Quick start

1. Install dependencies

```bash
npm install
```

2. Run the dev server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

Notes

- This scaffold provides a starting point. Replace placeholder images and content with your real assets.
- The contact form is a static form; integrate your backend or form provider as needed.
